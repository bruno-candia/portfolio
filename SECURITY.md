# Security Policy

## Reporting a Vulnerability

Please do not open a public issue for a suspected vulnerability.

Use GitHub's private vulnerability reporting form:

https://github.com/bruno-candia/portfolio/security/advisories/new

Include the affected component, reproduction steps, potential impact, and any
suggested mitigation. Do not include real credentials, personal data, or
production secrets in the report.

Receipt and next steps will be acknowledged through the private advisory. No
public disclosure timeline is promised before the issue has been assessed and
a safe remediation path exists.

## Supported Version

Security fixes target the current production version from `master`. Historical
commits and superseded deployments are not maintained as separate supported
versions.
